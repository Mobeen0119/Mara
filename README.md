# Mara

A personal execution agent. You give it a name, an email, a goal, a deadline, and the constraints
you're not willing to break. It emails you once a day, every day, until you mark the task done.
It does not motivate you. It tells you what's due and what's left, working around what you said
you won't do, and expects you to handle it.

Zero cost to run: local LLM via Ollama, your own free SMTP account for email, SQLite for storage.

## 1. Install

```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## 2. Set up Ollama (free, local, no API key)

Install from https://ollama.com, then:

```
ollama pull llama3.1
ollama serve
```

If Ollama isn't running, Mara still sends emails — it falls back to a built-in blunt message
template instead of the model.

## 3. Set up email (free)

Copy `.env.example` to `.env` and fill it in. Easiest free option is a Gmail account with an
[app password](https://myaccount.google.com/apppasswords) (not your normal password):

```
cp .env.example .env
```

## 4. Run it

```
uvicorn main:app --host 0.0.0.0 --port 8000
```

Open `http://localhost:8000`.

## How it works

- File a task with a goal, deadline, daily reminder time, and any constraints. The first
  message sends immediately — no waiting for the schedule.
- A background job checks every minute. Once a day, at your chosen time, it emails you the
  day's message, generated by your local Ollama model in Mara's voice.
- Each task has a daily check-in ("Did you get it done today?") and an open-ended chat you can
  use any time, day or night, to talk to Mara about that specific task.
- The task is not resolved by clicking a button. The day after the deadline passes, it
  automatically closes as SUCCEEDED (if you ever checked in "yes") or FAILED (if you never did).
- No login is required. Guest mode keeps your tasks tied to the browser you used. Create an
  account with a password if you want to reach the same tasks from another device.
- The dashboard shows a warning banner if email isn't configured or Ollama isn't reachable, so
  you know immediately why something isn't sending instead of guessing.

## Deploying for free

Any host with a persistent process works (Render, Railway, a spare machine, a Raspberry Pi).
Ollama needs to run somewhere reachable by `OLLAMA_URL` — same box is simplest. SQLite needs a
persistent disk, not an ephemeral filesystem.
